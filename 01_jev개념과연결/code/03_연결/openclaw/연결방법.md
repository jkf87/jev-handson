# OpenClaw에 Jev 붙이기

1) 설치: `npx skills add HyunjunJeon/jev-judgment -g -a openclaw` → `~/.openclaw/skills/jev-judgment`
2) 보이는지 확인: `openclaw skills info jev-judgment --agent <에이전트id>`
   - `✓ Ready` 면 끝.
   - `Excluded by agent allowlist` 면 `~/.openclaw/openclaw.json`의 `agents.entries.<id>.skills` 배열에 `"jev-judgment"`를 추가.
     (배열이 없는 에이전트는 모든 스킬을 본다. 2026-09-23 실측: gjc·testbot은 Ready, main은 허용목록에서 제외)
3) 키: 셸 환경변수 또는 `openclaw.json`의 `skills.entries.jev-judgment.env.TYPESAFE_API_KEY`
4) 시험: `openclaw agent --agent <id> --session-key agent:<id>:jev-test -m "<연결확인 프롬프트>"`
   (`--deliver`를 붙이지 않으면 텔레그램 등 채널로 보내지 않는다)
5) 한 번만 격리해서 돌리기: `openclaw agent exec --cwd <프로젝트> --json "..."` — 프로젝트의 `skills/` 폴더를 읽는다.
6) MCP로 붙이기: `openclaw mcp set jev '{"command":"python3","args":["/절대경로/jev_mcp_server.py"]}'`
