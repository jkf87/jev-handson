에이전트(Claude Code · Codex · OpenClaw)에 그대로 붙여 넣는 프롬프트 모음이에요. 슬라이드의 「프롬프트 ①~④」와 번호가 같아요.

1강 흐름: ① 첫 호출 → ② 스킬 설치 → ③ Jev로 악플 거르기 → ④ LLM으로 걸러서 두 출력 비교. 훅 · Codex · MCP는 맨 뒤 「더 해 보기」에 있어요.

- 키는 채팅에 붙여 넣지 말고 `.env`에 직접 적어요. 프롬프트에도 키 값은 절대 출력하지 말라고 넣어 뒀어요.
- 🔁 표시가 있으면 에이전트를 껐다 켜야 설정(스킬·훅·MCP)이 적용돼요.
- 예제 코드는 에이전트가 만들거나 실행할 코드의 기준 답안이에요. 결과가 다르면 비교해 보세요.
- 실측: 2026-09-23 Claude Code(`claude -p`, claude-sonnet-5)로 프롬프트를 한 번씩 그대로 돌린 기록 → `evidence/prompts/`

## ④ LLM으로 걸러서 두 출력 비교 — 어디서: `01_jev개념과연결/code`

```prompt 4
같은 50건을 LLM으로도 걸러서 두 출력을 비교해 줘.
python3 04_악플탐지/llm_filter.py --limit 50 (로그인된 claude CLI로 Claude Haiku를 불러, 1~2분 걸려)을 돌린 다음
python3 04_악플탐지/compare.py 로 정확도·정밀도·재현율·지연·1,000건 비용을 표로 보여 줘.
두 출력이 갈린 댓글은 정답과 함께 보여 주고, Jev 기준(악플 확률)을 0.3·0.5·0.7로 바꾸면 무엇이 달라지는지도 설명해 줘.
claude CLI가 없으면 --engine ollama:qwen3.5:4b 로 바꿔서 해 줘.
```

- 예제 코드: `code/04_악플탐지/llm_filter.py` (같은 정의를 시스템 프롬프트로 · 라벨 하나를 JSON으로) · `compare.py` (두 출력 맞춰 보기 · 기준 바꾸기)
- LLM은 라벨만 주고 확률은 주지 않아요. 그래서 "얼마나 확실하면 숨길지"를 코드가 고를 수 없어요. Jev는 확률이 있어서 API를 다시 부르지 않고 기준만 바꿔 다시 채점할 수 있어요
- 9/23 실측(152초, 같은 50건): Haiku 악플 정밀도 96.4% · 재현율 87.1% · F1 0.915 · 7.9초 · 1,000건 $3.69 / Jev 92.9% · 83.9% · 0.881 · 0.43초 · $0.023. 판단이 갈린 댓글은 4건(일치 92%), Jev 기준을 0.3으로 내리면 F1 0.918로 Haiku와 같은 수준. 기록: `evidence/prompts/4_LLM과_비교.jsonl`
- 471건 전부(강사 실행, `code/04_악플탐지/results/`): 둘 다 성공한 462건에서 Jev F1 0.883 · Haiku 0.875, 3분류는 Haiku 67.3% · Jev 63.0%, 지연 0.36초 vs 8.1초, 1,000건 $0.023 vs $3.62. Haiku는 9건 실패(시간 초과 7 · 형식 오류 2)
- 50건은 한두 건에 결과가 흔들려요. 같은 댓글을 Haiku가 50건 시험 땐 잡고 471건 땐 놓친 경우도 있었어요(LLM은 돌릴 때마다 답이 바뀜)
