# 활용 사례 맛보기 — 컴퓨터 · 게임 · 로봇

3강 활용 사례(jev-ultrafast, CMO·게임 에이전트, jev-drone)의 뼈대만 남긴 예제 세 개입니다. 셋 다 같은 모양이에요.

```text
상황을 글로(state) → Jev가 선택지 중 하나를 고름(Choice) + 위험한가(Noul) → 코드가 확률을 보고 실행·확인·멈춤을 정함
```

Node.js 20 이상, 외부 패키지 없음. 키는 환경변수 `TYPESAFE_API_KEY` → 실행 폴더 `.env` → `code/.env` 순서로 찾습니다.
3강 로컬 decider 서버로 바꾸려면 `TYPESAFE_BASE_URL=http://127.0.0.1:8000`만 붙이면 됩니다(키 없이).

```sh
cd 03_유사프로젝트/code
node usecases/pick_element.mjs        # 컴퓨터 유즈: 화면 요소 표에서 누를 요소 고르기 (호출 3번)
node usecases/game_move.mjs           # 게임: 틱택토 판 3개 (이기기 · 막기 · 첫 수)
node usecases/game_move.mjs --play    # 게임: 규칙 봇(O)과 한 판
node usecases/robot_action.mjs        # 로봇: 센서 글 → 다음 행동 하나 (호출 4번)
node --test usecases/usecases.test.mjs   # 키 없이 시험 3개(정책·게임 규칙)
node usecases/robot_action.mjs --replay usecases/results/robot_action-2026-09-23T05-48-14-430Z.json   # 키 없이 기록 재생
```

| 예제 | Jev가 고르는 것 | 코드가 정하는 것 (강의용 시작값) |
|---|---|---|
| `pick_element.mjs` | 요소 표(e1~e8) 중 누를 것, 없으면 none · 되돌릴 수 없는 동작인가 | 0.7 미만이면 되묻기, 되돌릴 수 없으면(0.5 이상) 사람에게 확인 |
| `game_move.mjs` | 빈칸 중 둘 곳 (둘 수 있는 칸만 선택지로) | 0.4 미만이면 규칙(이기기 → 막기 → 가운데·모서리)이 대신 둠, 판 끝 판정 |
| `robot_action.mjs` | 앞으로 · 왼쪽 · 오른쪽 · 집기 · 멈춤 · 충전하러 가기 · 부딪칠 위험이 있나 | 0.6 미만이면 멈춤, 위험(0.3 이상)인데 움직이려 하면 멈춤 |

## 파일

| 파일 | 역할 |
|---|---|
| `jev.mjs` | Jev 클라이언트(키·주소), 시나리오 실행 틀, `--replay`, 기록 저장 |
| `pick_element.mjs` · `game_move.mjs` · `robot_action.mjs` | 예제 세 개. 각각 `buildRequest`(질문) · `decide`(정책) · `SCENARIOS` |
| `usecases.test.mjs` | 키 없이 정책과 게임 규칙 시험 |
| `results/` | 9/23 실측 기록(재생용) |
